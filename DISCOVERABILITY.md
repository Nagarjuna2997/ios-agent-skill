## Reusable project description

**iOS Agent Skill** gives AI coding agents local Swift source, Apple guides, and MCP tools for reviewing and building iOS apps. It includes a 405-entry Apple technology directory, bounded local reference retrieval, 11 read-only Swift review tools, app scaffolding with editable icon layers, and an optional 14-tool macOS/Xcode simulator server with a private browser preview. Client setup is available for Claude, Codex and Gemini CLI, with portable references for ChatGPT workflows. MIT licensed.

Install the skill:

```bash
npx skills add Nagarjuna2997/ios-agent-skill
```

Repository: https://github.com/Nagarjuna2997/ios-agent-skill

The catalog is not 405 completed implementations. Simulator tools require a Mac and Xcode. No measured token-saving percentage or automatic app-completion promise is made.

## What to measure

Use GitHub traffic/referrers and clones, npm downloads, useful issue reports, and contributed examples to see whether discovery brings real use. These metrics are imperfect: downloads can include automation and stars are not active users. Prioritize a reliable first install and reproducible examples that people can recommend. Avoid artificial installs, purchased stars, or duplicate submissions. No X promotion was posted for this update.

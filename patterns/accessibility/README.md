# Accessibility Patterns

| Pattern | Use | Rule |
|---|---|---|
| semantic button label | icon-only controls | label names the action |
| custom action | complex row/card controls | expose one clear VoiceOver path |
| Dynamic Type layout | text-heavy screens | wraps without clipping |
| Reduce Motion fallback | parallax/3D/large movement | opacity or instant state |
| focus order | forms and flows | matches visual/task order |

Accessibility is not a final pass. It shapes layout, state, motion, and testing from the first implementation.

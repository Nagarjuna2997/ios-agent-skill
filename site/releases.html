Inspect the app. Prepare the evidence.

This patch adds conservative launch-screen reviews and the first local release-preparation workflow. It helps you identify missing project facts before attempting a release.

Launch-screen review

The existing App Store audit and project analysis now inspect launch configuration, storyboard and asset references using selected-target evidence. Thirteen diagnostics have regression coverage; unresolved settings remain explicit coverage gaps.

Checks and supported configurations →

Local release preparation

Use apple analyze to inspect a target and apple prepare to create an integrity-hashed local draft. The output separates observed facts, inferred candidates and unanswered questions. Unchanged inputs reuse a verified package; changed evidence creates a new package.

npx -y ios-agent-mcp@latest apple analyze --project /path/to/app --target App --configuration Release --json
npx -y ios-agent-mcp@latest apple prepare --project /path/to/app --target App --configuration Release --json

This phase does not connect to Apple, run an AI provider, archive, sign, upload or submit an app. Draft evidence is not a release approval.

Fixes and verification

  • Corrected JSONDecoder/JSONEncoder formatter false positives.
  • 248 MCP tests pass, including 29 launch tests and 52 release-preparation tests.
  • Twelve launch benchmark fixtures include valid and broken configurations, diagnosis/fix checks and unnecessary-change detection. Agent trials for these tasks have not been run.

The previous benchmark stays unchanged: 120 runs, 60/60 passes in each arm, and 60 paired ties. We do not claim measured improvement from this update.

Private reporting remains experimental

The 37th unified tool, private_feedback, requires a configured HTTPS receiver and explicit preview approval. Hosted delivery is not live by default. No silent public submission is added.

Next milestone

Evaluate the harder launch-screen tasks, inspect diagnosis quality and unnecessary changes, and resolve unsupported project configurations before extending release automation.
